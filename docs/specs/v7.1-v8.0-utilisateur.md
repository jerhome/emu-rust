# Spécifications utilisateur — 7.1, 7.2 et 8.0 (début, 2026-11-21)

Texte fourni par l'utilisateur (le 2026-11-21) ; complété au fil de ses messages. Fait autorité sur le périmètre ;
la conception (ADR + design) en découle.

## 7.1 (première partie, d'autres points peuvent suivre)

1. **Pied de page de l'interface** : afficher la **version** et la mention **« dev by claude@jerhome »**.
2. **Icône d'application** : simple, évidente, moderne, **identique sur Windows, macOS et Linux**, dans le style de
   l'interface actuelle (que l'utilisateur aime).
3. **Terminal caché par défaut** (Windows : pas de console) ; un **réglage** permet de le réafficher **après
   redémarrage**. Les informations importantes que le terminal affiche aujourd'hui doivent être envisagées **dans
   l'interface** (journal, messages).
4. **Réglages → créer la structure de `roms/`** (un dossier par système) **et y déplacer les ROMs** existantes, avec
   les mises à jour nécessaires dans l'application (bibliothèque, favoris, sauvegardes, options de jeu, identités).
5. **Avertissement sur les cores qui seraient améliorés par un fichier commercial** (interprétation à confirmer :
   BIOS/firmware d'origine que l'utilisateur fournit lui-même — PS1, 3DO, Amiga (Kickstart), GBA, Mega CD… —
   jamais téléchargé par l'application, conformément à CLAUDE.md).

## 7.2

- **Mega CD + 32X (« Sega CD 32X »)**, ex. Night Trap 32X : pas urgent (décision du 2026-11-21).

## 8.0

- **Machines compatibles libretro non testées, gérables depuis l'application** : permettre d'ajouter et d'utiliser
  des systèmes / cores libretro qu'emu-rust ne connaît pas encore (non testés par nous). L'utilisateur s'attend à un
  gros chantier.
