# Design 7.3 — Refonte visuelle et accompagnement

Décisions de l'utilisateur (2026-11-24, roadmap) : thème sombre seul, grille de jaquettes, accent `#4aa3ff`, manuel intégré
(bouton « Aide », F1 + raccourci sans touche F), « ? » contextuel, assistant de premier lancement. Pas d'ADR : aucune
dépendance de crate ni `unsafe` nouveaux. Existant : `ui::apply_style` (`ui/mod.rs:557`, `Visuals::dark()` + focus bleu),
couleurs locales en `const` dans `library/mod.rs` (ex. `ERROR`), grille déjà en place (`library/home.rs`, `grid.rs`,
cartes 168x254, `show_rows`), jaquettes `library/covers.rs` (LRU, `MAX_TEXTURES = 256`), textes FR dans `library/text.rs`
et `ui/text.rs`, `Page {Home, Settings, Cores}`, apprentissage manette dans `library/pad_settings.rs`.

## 1. Thème (`crates/emu-ui/src/theme.rs`, nouveau, `pub(crate)`)
- `theme::apply(ctx)` remplace `apply_style` (qui l'appelle ; animations à 0 conservées, captures déterministes).
- Couleurs (`const Color32`) : `BG #14171d`, `PANEL #1b1f27`, `CARD #232834`, `CARD_HOVER #2b3140`, `TEXT #e6e9ef`,
  `TEXT_WEAK #8d95a6`, `ACCENT #4aa3ff`, `ACCENT_DIM #28507f` (fond sélection), `OK #5cc98a`, `WARN #e8b84a`,
  `ERROR #ff6e6e` (reprend l'existant). Contraste texte/fond >= 7:1.
- Tailles : police corps 15, petit 12, titre 22, titre de section 18 (polices egui par défaut : pas de fonte à embarquer).
  Espacements : `SP_XS 4`, `SP_S 8`, `SP_M 12`, `SP_L 20`; rayon `RADIUS 6`; trait de focus 2 px `ACCENT` (inchangé en
  fonction : le focus clavier/manette reste le signal principal).
- Helpers : `theme::card_frame(selected)`, `theme::section_title(ui, txt)`, `theme::hint(ui, txt)`, `theme::badge(ui, txt, color)`.
- Règle : plus aucun `Color32::from_rgb` hors `theme.rs` (migration progressive, un grep en test d'architecture à la fin de T1).
- Interdits : flou, ombres portées étendues, dégradés par frame, animations.

## 2. Grille de jaquettes (évolution de `home.rs`)
- Tuile 168 x 210 (ratio 4:5, jaquette ajustée `contain` sur fond `CARD`) + titre sur 2 lignes (44 px) ; écart `SP_M`.
- Placeholder sans jaquette : rectangle `CARD` + initiales du titre (2 lettres, 36 px, `TEXT_WEAK`) + pastille du système
  en bas ; aucune texture allouée.
- Sélection : cadre `ACCENT` 2 px + fond `CARD_HOVER` ; pas de zoom animé. Défilement : `show_rows` existant, sélection
  toujours visible (déjà géré). Navigation `grid::step` inchangée (clavier, manette).
- Systèmes à gauche : panneau latéral `PANEL` 180 px, entrée active en `ACCENT_DIM`, compteur à droite en `TEXT_WEAK`.
- Cache : inchangé (textures créées seulement pour les cartes visibles, LRU 256). Baisser `MAX_TEXTURES` à 128 et
  décoder les jaquettes à <= 336 px de large (2x la tuile) si ce n'est pas déjà le cas.

## 3. Manuel intégré (`crates/emu-ui/src/help/{mod,markdown}.rs`)
- Source `docs/manuel.md` embarquée par `include_str!("../../../../docs/manuel.md")` ; une seule source de vérité.
- Rendu : **sous-ensemble maison**, pas de crate (le manuel n'utilise que `#/##/###`, paragraphes, listes `-`/`1.`, `**gras**`,
  `` `code` ``, tableaux simples, liens non cliquables). `markdown::parse(&str) -> Vec<Block>` (pur, testable) puis
  `help::show(ui, &Doc, &mut HelpState)`. Tableaux : `egui::Grid`. Un tableau ou une syntaxe inconnue s'affiche en texte brut
  (jamais de panique). Pas de `egui_commonmark` (poids : pulldown-cmark + syntect optionnel, inutile ici).
- Disposition : table des matières à gauche (les `## N.` du manuel : 1 Premiers pas ... 7 Problèmes), contenu à droite en
  `ScrollArea`; Haut/Bas défilent, Gauche/Droite changent de section, Échap ferme. `HelpState { section, scroll }`.
- Accès : bouton « Aide » (barre du haut de la bibliothèque), `F1`, et **`?`** (texte tapé, hors champ de saisie ; sur AZERTY
  c'est Maj+`,`, donc aussi `Ctrl+H` en secours sans F ni Maj ; jamais `Cmd+H`, qui masque l’app sous macOS) ; menu en jeu : entrée « Aide » (§6). Cohérent avec le
  clavier 60 % : aucun raccourci ne dépend d'une touche F. Les raccourcis machine (hôte) ne changent pas.
- Ouverture en `Page::Help(Option<Section>)` de la bibliothèque ; en jeu, via `Screen::Help` de l'overlay (jeu en pause).

## 4. Assistant de premier lancement (`library/wizard.rs`)
- S'affiche quand `config.library.roots` est vide **et** `[ui] wizard_done` absent/faux (nouvelle clé de config, défaut faux ;
  un utilisateur existant avec des roots ne le voit pas). Relance : Réglages > « Relancer l'assistant » et `--wizard` en CLI.
- Étapes (bandeau d'étapes 1/4, Suivant / Retour / Passer, tout au clavier) :
  1. Bienvenue : une phrase, lien vers l'Aide.
  2. Dossier des ROMs : sélecteur (`file_picker.rs`) puis scan immédiat avec progression (réutilise le scan existant).
  3. Cores : liste des systèmes trouvés au scan, case « installer » (cores manquants), via la page Cores ; sans réseau :
     message actionnable (§5).
  4. Commandes : clavier (touche hôte rappelée) et manette ; si une manette est branchée, ouvre l'apprentissage 7.2
     (`pad_settings.rs`, restylé via `theme`) ; sinon « Plus tard dans Réglages ».
- Fin : `wizard_done = true`, arrivée sur la bibliothèque. BIOS manquants : rappel avec renvoi vers `firmware_banner`.

## 5. États vides et erreurs
- Textes centralisés dans `library/text.rs` (`EMPTY_*`, `ERR_*`), format « constat + action » : ex. « Aucun jeu. Ouvrez
  Réglages > Dossiers pour ajouter votre dossier de ROMs. » avec bouton direct.
- États vides : bibliothèque sans roots (bouton « Choisir le dossier » + « Lancer l'assistant »), roots sans jeux (formats
  reconnus + « Rescanner »), filtre/recherche sans résultat (« Effacer le filtre »), Favoris/Récents vides (comment
  ajouter), page Cores sans core (bouton Installer), liste de disques vide.
- Erreurs : type `UserMessage { what, fix }` rendu par `theme::error_box` (rouge `ERROR`, icône texte, ligne « Que faire »).
  Cas à couvrir : core absent, BIOS manquant/mauvais hash, ROM introuvable, téléchargement échoué (réseau, hash invalide),
  dossier illisible. Jamais de secret ni de chemin complet inutile dans le message.

## 6. Aide contextuelle
- « ? » discret (`TEXT_WEAK`, 16 px, focusable) à côté de chaque réglage ; clic ou Entrée ouvre une bulle (`Popup`) d'une
  à deux phrases, avec lien « En savoir plus » vers la section du manuel. Table `help::topics` (clé -> texte + section).
- Menu en jeu (`ui/menu.rs`) : entrée « Aide » -> `UiAction::OpenHelp`, ouvre `Screen::Help`.
