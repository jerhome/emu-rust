# Version 1.0 — Bibliothèque de jeux et jaquettes : contrat et découpage

Décisions : **ADR 0014** (précise 0005, 0006). Gestionnaire de cores : ADR 0013 / `docs/design/v1.0-cores.md`
(conçu en parallèle ; jonction par le **nom de base libretro** du système et `emu_assets::cores::choose_core`).
Systèmes : Mega Drive, SNES, NES, Game Boy, Game Boy Color, Game Gear, Master System.

## 1. Scan, hash, identification, base

**Catalogue** `crates/emu-library/data/systems.toml` (embarqué) : `id`, nom, extensions, règle d'en-tête, `database`
(nom libretro), ids ScreenScraper / IGDB. Ids de plateforme à vérifier par L1 sur la doc des API (pas d'appel réseau).

| id | extensions | en-tête | `database` | SS | IGDB |
|---|---|---|---|---|---|
| `megadrive` | md gen smd bin | — | Sega - Mega Drive - Genesis | 1 | 29 |
| `snes` | sfc smc | copieur 512 o | Nintendo - Super Nintendo Entertainment System | 4 | 19 |
| `nes` | nes unf unif | iNES 16 o | Nintendo - Nintendo Entertainment System | 3 | 18 |
| `gb` / `gbc` | gb / gbc | — | Nintendo - Game Boy (Color) | 9 / 10 | 33 / 22 |
| `gamegear` | gg | — | Sega - Game Gear | 21 | 35 |
| `mastersystem` | sms | — | Sega - Master System - Mark III | 2 | 64 |

**Scan** (`Library::scan`, thread de travail) : racines = `<data>/roms` + `library.roots` ; parcours sans suivre les
liens symboliques de dossiers, profondeur ≤ 8. Fichier retenu si son extension (ou, pour un `.zip`, celle de la
**première entrée acceptée**, même règle que `emu-runtime`) est au catalogue. Un zip = un jeu. Système : composant de
chemin égal à un `id` (`roms/gb/…`) > correspondance DAT parmi les systèmes de l'extension > premier du catalogue.
Incrémental : (chemin, taille, mtime) inchangés ⇒ pas de re-hash. Fichier disparu ⇒ supprimé, **sauf** si sa racine
est absente (disque non monté : `ScanReport::missing_roots`). Erreurs par fichier collectées, le scan continue.
Annulable (`AtomicBool`), progression ≤ 10 Hz.

**Hash** (`hash_reader`) : CRC32 (`crc32fast`) + SHA1 (`sha1`, RustCrypto) en un passage, tampon 64 Kio, jamais de
lecture complète en mémoire. Taille > `MAX_HASH_SIZE` (512 Mio) ⇒ listé non haché ; zip > 1 Gio ⇒ erreur, non listé (cohérent avec `emu-runtime`). Zip : entrée décompressée en flux,
taille déclarée **et** octets lus bornés (bombe), `zip` aux features du workspace. Hashes « sans en-tête » en plus
quand la règle s'applique (NES `NES\x1A`, SNES `taille % 1024 == 512`).

**DAT** : No-Intro au format clrmamepro, `libretro-database/metadat/no-intro/<database>.dat`
(`raw.githubusercontent.com`, HTTPS). Téléchargés par `emu-assets::download_dat` vers `<data>/database/no-intro/`
(GET conditionnel `If-None-Match`, ≤ 64 Mio, écriture atomique), importés par `Library::import_dat` (transaction,
puis ré-identification du système). Premier scan sans DAT : téléchargement proposé ; bouton « Mettre à jour la base »
dans les réglages ; jamais automatique en arrière-plan sans action ou premier lancement. Licence : DAT No-Intro
redistribués par libretro ; **nous ne les redistribuons pas** (téléchargés chez l'utilisateur, usage personnel). Les
DAT de test sont **écrits à la main** (jeux fictifs), jamais copiés. Le `.rdb` n'est pas lu.
Correspondance : SHA1 (plein ou sans en-tête) > CRC32 + taille > nom de fichier normalisé = nom DAT > inconnu (titre =
nom de fichier, jouable).

**SQLite** : `rusqlite` + `bundled` (MIT ; SQLite domaine public ; compilé par `cc`, déjà requis). `journal_mode=WAL`,
`foreign_keys=ON`, une connexion par thread. Schéma v1 (`PRAGMA user_version = 1`) :

```sql
CREATE TABLE dat_info  (system TEXT PRIMARY KEY, name TEXT NOT NULL, version TEXT, entries INTEGER NOT NULL,
                        imported_unix INTEGER NOT NULL, etag TEXT);
CREATE TABLE dat_entry (system TEXT NOT NULL REFERENCES dat_info(system) ON DELETE CASCADE, game TEXT NOT NULL,
                        rom_name TEXT NOT NULL, size INTEGER NOT NULL, crc32 INTEGER NOT NULL, sha1 BLOB);
CREATE INDEX dat_entry_sha1 ON dat_entry(sha1);  CREATE INDEX dat_entry_crc ON dat_entry(system, crc32, size);
CREATE TABLE game (id INTEGER PRIMARY KEY, path TEXT NOT NULL, entry TEXT, system TEXT NOT NULL,
                   file_size INTEGER NOT NULL /* disque, scan incrémental */, size INTEGER NOT NULL /* contenu haché */,
                   mtime_unix INTEGER NOT NULL, pinned INTEGER NOT NULL DEFAULT 0 /* v2 : système fixé par dossier, appliqué par reidentify */, crc32 INTEGER, sha1 BLOB,
                   crc32_nh INTEGER, sha1_nh BLOB, title TEXT NOT NULL, identification TEXT NOT NULL,
                   favorite INTEGER NOT NULL DEFAULT 0, last_played_unix INTEGER, play_count INTEGER NOT NULL DEFAULT 0,
                   UNIQUE(path));  -- game.path UNIQUE (un zip = un jeu), pas UNIQUE(path, entry)
CREATE TABLE cover (game INTEGER NOT NULL REFERENCES game(id) ON DELETE CASCADE, kind TEXT NOT NULL,
                    state TEXT NOT NULL /* cached|missing */, path TEXT, source TEXT, checked_unix INTEGER NOT NULL,
                    PRIMARY KEY (game, kind));
```

**Scan (implémenté)** : hachage hors transaction, lots de 128 fichiers ou 2 s, annulation possible pendant le hachage. **DAT** : budget de 65 536 nœuds par bloc de premier niveau, blocs inconnus sautés ; base plus récente sondée en lecture seule. **Systèmes** : `gbc` accepte aussi `.gb` (classé gbc via `roms/gbc/` ou DAT GBC) : U4 et le choix du core doivent l'accepter (gambatte gère les deux). **Id inconnu** : `record_played`/`set_favorite` sans effet, `set_cover` renvoie `Database` (asymétrie documentée).

Chemins stockés en texte UTF-8 ; un chemin non UTF-8 est ignoré avec avertissement (cible Windows/macOS/Linux
usuelle). Migrations : tableau ordonné de scripts SQL embarqués, chacun dans une transaction qui écrit `user_version`.
`SCHEMA_VERSION = 2` (v2 : colonne `pinned`). `user_version` > `SCHEMA_VERSION` ⇒ `NewerSchema`, fichier intact, l'UI affiche l'erreur et fonctionne sans base.
Ouverture : erreur « not a database » / `quick_check` ≠ `ok` ⇒ renommage `library.sqlite.corrupt-<unix>` (+ `-wal`,
`-shm`), base neuve, `OpenOutcome::Recovered` (bandeau dans l'UI). Le cache de jaquettes sur disque survit.

## 2. Jaquettes

Ordre par défaut `covers.sources = ["libretro", "screenscraper", "igdb"]` ; une source sans identifiants est sautée.

| Source | Requête | Limites / erreurs |
|---|---|---|
| libretro-thumbnails | `GET https://thumbnails.libretro.com/<database>/Named_Boxarts/<nom>.png`, `nom` = titre DAT (sinon nom de fichier) avec ``&*/:`<>?\|"`` → `_`, encodé en pourcentage | 404 = absent ; sans compte |
| ScreenScraper | `GET api2/jeuInfos.php?devid&devpassword&softname=emu-rust&output=json&ssid&sspassword&systemeid&crc&sha1&romtaille&romnom` ; média `box-2D` (région : wor > eu > us > jp > premier), puis `GET` de l'URL média | Une requête à la fois ; 401/403 ⇒ source coupée (identifiants) ; 429/430 ⇒ coupée pour la session (quota) ; 404 = absent. **URL jamais loggée** (identifiants dans la requête) |
| IGDB | `POST id.twitch.tv/oauth2/token` (client credentials ; jeton en mémoire) ; `POST api.igdb.com/v4/games` corps `search "<titre>"; fields name,cover.image_id; where platforms = (<igdb>); limit 5;` ; image `images.igdb.com/…/t_cover_big/<image_id>.jpg` | ≤ 4 req/s ; 401 ⇒ un renouvellement du jeton puis coupure ; 429 ⇒ `Retry-After` |

Validation : ≤ `MAX_COVER_BYTES` (8 Mio, lecture bornée) ; format par **signature** (PNG, JPEG ; rien d'autre) ;
`decode_cover` (`image` 0.25, features `png` + `jpeg` seulement, `Limits` : côtés ≤ 4096, allocation ≤ 64 Mio) avant
toute écriture ; réduit à 512 px pour l'affichage. Cache `<data>/covers/<id>/boxart/<sha1 hex>.<png|jpg>` (clé =
hash du chemin si non haché), écriture atomique ; `CoverCache::resolve` refuse tout chemin de la base sortant du cache.
Absence partout ⇒ `CoverState::Missing`, nouvel essai après `covers.retry_days` (30) ou « Rechercher à nouveau ».

File (thread `emu-ui`, `emu_assets::jobs::Job` d'ADR 0013) : jeux visibles d'abord, puis le reste par titre ; une
requête à la fois par source. **Hors ligne** : 3 erreurs réseau consécutives ⇒ source suspendue pour la session ;
toutes suspendues ⇒ indicateur « hors ligne », rien n'est marqué `Missing`. `covers.download = false` ⇒ cache seul.

## 3. Interface egui

**Accueil bibliothèque** : barre du haut (recherche, filtres système « Tous / Mega Drive / … » avec compteurs,
favoris, tri titre / dernière partie, bouton Réglages) ; grille de jaquettes (taille fixe, titre sous l'image,
substitut = nom du système si pas d'image) ; barre d'état (scan en cours n/m, DAT manquant, hors ligne, base récupérée).
Navigation clavier : flèches dans la grille, Entrée = lancer, `F` favori, `/` ou Ctrl+F recherche, Tab vers les
filtres, Échap = vider la recherche. Mêmes événements egui injectables par la manette (phase 6). Textures : décodage
dans le thread de travail, envoi en texture egui seulement pour les cases visibles, LRU ~256 textures.

**Lancement** : `choose_core(Some(&system.database), Some(ext), installed, infos, prefs)` (ADR 0013) :
`Installed(id)` ⇒ partie dans la même fenêtre (même contexte GL, `Emulator` créé puis détruit dans l'ordre de la
phase 2) ; `Install(id)` ⇒ dialogue « Installer <core> ? » vers le gestionnaire de cores ; `Unknown` ⇒ message.
Le menu en jeu gagne « Retour à la bibliothèque » ; `record_played` au lancement réussi. Profils de touches : inchangés
(par `core_id`).

**Réglages bibliothèque** : dossiers de ROMs (liste, ajout par champ texte, suppression ; `<data>/roms` fixe),
« Scanner maintenant », « Mettre à jour la base (DAT) » avec date par système, ordre et activation des sources,
identifiants ScreenScraper (dev id, dev mot de passe, utilisateur, mot de passe) et IGDB (client id, secret).
Secrets : `TextEdit::password(true)`, **jamais pré-remplis** ; état affiché « défini » / « non défini », boutons
« Modifier » / « Effacer ». Écrits par `Config::save` (0600, atomique) ; config verrouillée (ADR 0011) ⇒ pas d'écriture.
Aucun `Debug` de `Config` dans les logs (le type `Secret` le masque de toute façon).

## 4. Lancement sans `--core/--rom`

`cli::Command::NoArgs` (double-clic) **et** `emu-rust [--data-dir D] [--no-audio] [--screen library|library-settings
--dump-window F]` sans `--core/--rom` ⇒ `emu_ui::run_library(LibraryOptions)`. Un seul de `--core`/`--rom` ⇒ erreur.
Arguments `-psn_*` (anciens macOS, Finder) ignorés. Windows : sous-système console conservé (question ouverte).
`--screen library*` : pas de scan ni de réseau, base et cache lus tels quels (captures Xvfb déterministes).

## 7. Découpage

| Tâche | Agent (modèle) | Fichiers | Dépend de |
|---|---|---|---|
| **L1** Bibliothèque | `library-assets` (**opus** : données non fiables, SQLite, zip) | `crates/emu-library/**` (§1, §6.1) + tests unitaires et `tests/{scan,db}.rs` | — |
| **L2** Jaquettes et DAT | `library-assets` (**opus** : réseau, secrets, décodage d'images) | `crates/emu-assets/src/{covers,dat,image,secret}.rs`, `Cargo.toml` | A1 (ADR 0013 : `http.rs`, `jobs.rs`) ; même agent, **après** L1 ou en séquence avec A1 (crate partagé) |
| **Q1** Données de test | `qa-systems` (sonnet) | `tests/data/dat/sample.dat`, JSON ScreenScraper / IGDB faits main, `tests/data/library/` (arborescence de fixture pour captures) | — |
| **U3** Config et CLI | `ui` (sonnet) | `crates/emu-ui/src/{config,config_library}.rs`, `crates/emu-app/src/{cli,main}.rs` (NoArgs ⇒ `run_library`, `-psn_`, `--screen library*`) | — |
| **U4** Écrans bibliothèque | `ui` (**opus** : machine d'états jeu ⇄ bibliothèque dans un même contexte GL, threads) | `crates/emu-ui/src/{app,lib}.rs`, `src/library/{mod,home,settings,worker,textures}.rs` | L1, L2, U3, écran du gestionnaire de cores (ADR 0013) pour `Install` |
| **Q2** Vérification complète | `qa-systems` (sonnet) | fmt/clippy/test, `--ignored`, captures Xvfb `library` / `library-settings`, image Docker (dind, `ca-certificates`) | U4 |
| **V1** Revue | `reviewer` (**opus**) | réseau (HTTPS, limites, `without_url`), secrets (logs, erreurs, UI, 0600), décodage d'images, zip, SQL (requêtes paramétrées), licences (`ring`, `rusqlite`/SQLite, `image`, `zune-jpeg`, `rustls-platform-verifier`) | Q2 |
| **E1** Essai réel | **utilisateur** | double-clic sur les 4 plateformes, scan de ses ROMs, jaquettes, identifiants ScreenScraper/IGDB | V1 |

Vagues : 1. **L1** ‖ **U3** ‖ **Q1** (‖ A1 d'ADR 0013 si `library-assets` n'est pas déjà pris par L1 : une seule
instance par crate) ; 2. **L2** (après A1) ; 3. **U4** ; 4. **Q2** → **V1** → **E1**.
`emu-library` et `emu-assets` étant deux crates distincts, L1 et A1 peuvent tourner en parallèle sur deux instances
de `library-assets`. Besoins hors périmètre : dans le résumé final, repassent par l'`architecte`.
