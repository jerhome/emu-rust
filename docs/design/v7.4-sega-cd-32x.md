# 7.4 — Sega CD 32X (conception courte, 2026-11-24)

## 1. État actuel (vérifié dans le code)
- Mega CD : système `megacd` (`systems.toml`), scan par `.cue/.chd/.iso/.m3u`, sonde `SEGADISCSYSTEM` (`disc.rs`),
  région lue à l'en-tête, DAT Redump « Sega - Mega-CD - Sega CD ». Core par défaut genesis_plus_gx, picodrive en 2e choix
  (`cores.toml`, `required_firmware` des deux cores), BIOS `bios_CD_E/U/J.bin` couverts par `firmware_hints.toml`
  pour **les deux** cores (système `megacd`), CHD en `media_direct` pour les deux.
- 32X cartouche : système `32x` (`.32x`, `.bin` avec `SEGA 32X` à 0x100), core picodrive, BIOS 32X intégrés.
- **Manque** : aucune notion de « CD 32X ». Un disque 32X est aujourd'hui classé `megacd` et ouvert par
  genesis_plus_gx, qui n'émule pas la 32X : le disque démarre au mieux en mode Mega CD seul, ou échoue.
- Donc « presque fini » : vrai pour le plomberie (BIOS, choix de core, CHD), faux pour la reconnaissance et, surtout,
  **pour la certitude que picodrive sait jouer ces disques** (voir §3).

## 2. Réponses aux questions
1. **Reconnaissance** : pas de DAT dédié (libretro-database n'a pas de « Sega CD 32X » ; Redump range ces disques
   dans « Mega-CD - Sega CD »). L'en-tête 0x100 du secteur 0 est celui du Mega CD (`SEGADISCSYSTEM`) ; la chaîne
   `SEGA 32X` n'y figure pas de façon garantie (je ne peux pas le vérifier sans disque). Méthode : lire les
   premiers Ko de la piste 01 du disque de l'utilisateur (sonde §3) et chercher `32X`/`SEGA 32X`/`MARS` dans
   l'IP.BIN ; à défaut, **liste de titres connus** (Night Trap 32X, Fahrenheit 32X, Corpse Killer 32X, Slam City,
   Surgical Strike, Supreme Warrior, Tomcat Alley…) par nom DAT Redump contenant « 32X ». Le hash seul ne suffit pas.
2. **Système** : pas de système `segacd32x` (un 2e système sur les mêmes extensions casse `folder_extensions`
   et le regroupement multi-CD). Variante du jeu : champ `variant`/drapeau `needs_32x` sur `megacd`, qui force le
   core picodrive via une préférence de core **par jeu** (mécanisme existant, test `preferred_core_is_written_and_cleared`),
   `choose_core` inchangé. Base DB `Sega - Mega-CD - Sega CD` conservée (jaquettes, hash).
3. **BIOS** : déjà couvert (table `required_firmware` picodrive pour `megacd`). Rien à ajouter ; ajouter une `note`
   « CD 32X : BIOS Mega CD requis ; BIOS 32X intégrés ». Le lancement d'un jeu `megacd` vérifie déjà la région.
4. **CHD** : picodrive déclare `chd` et `.info` aussi ; le plugin est déjà en `media_direct`. À confirmer par la sonde ;
   si KO, message clair « CHD non lu par picodrive : utiliser .cue/.bin » (pas de conversion).
5. **Jaquettes** : inchangées (base Mega CD, ScreenScraper `megacd` = 20).

## 3. Étape 0 : sonde (bloquante, utilisateur ou poste avec le disque)
Lancer le disque 32X dans picodrive (RetroArch ou `emu-rust` avec core picodrive choisi à la main) : démarre-t-il en
mode 32X ? Relever aussi les 0x200 premiers octets de la piste 01 (`xxd`) pour la signature.
- **Si picodrive démarre en 32X** : suivre §4.
- **Sinon** : abandonner le « CD 32X ». Livrer seulement une note du manuel (« jouer l'édition Mega CD du jeu »)
  et clore la 7.4 en roadmap ; aucun autre émulateur libretro ne couvre la combinaison.

## 4. Tâches (si la sonde est positive) — taille globale : petite à moyenne
1. `library-assets` : `disc.rs` — nouvelle valeur `DiscInfo`/`DiscFormat` « Sega CD 32X » (signature IP.BIN trouvée
   en §3) ; `scan.rs` — marque le jeu `megacd` avec `needs_32x` (colonne SQLite via migration) ; repli par nom
   Redump « 32X ». Tests : disque factice fabriqué (comme `mkcd.py`), sans ROM commerciale. `emu-assets` :
   `note` dans `firmware_hints.toml`.
2. `ui` (après 1) : à l'ajout/lancement, `needs_32x` ⇒ préférence de core `picodrive` si installé, sinon proposition
   d'installer picodrive ; badge « 32X » dans la fiche ; manuel utilisateur.
3. `qa-systems` (après 1 et 2) : test d'intégration du scan sur disque factice, choix du core, vérification complète.
   Aucun test de jeu réel (pas de BIOS ni de disque ici).
Parallélisme : 1 seul chemin critique ; 1 puis 2 puis 3.

## 5. À essayer par l'utilisateur
Avec ses BIOS Mega CD et le disque 32X (Night Trap ou Fahrenheit 32X) : (a) la sonde §3 d'abord ; (b) puis ajout du
dossier au scan : le jeu apparaît avec le badge 32X, se lance avec picodrive, image 32X, son CD et sauvegarde OK ;
(c) un jeu Mega CD ordinaire reste lancé par genesis_plus_gx.
