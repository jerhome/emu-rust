# Version 3.0 — Amiga, import de BIOS, dossier des ROMs : contrat et découpage

Décisions : **ADR 0017** (statut proposé ; précise 0005, 0013, 0014, 0015). Étude préalable : `docs/essais-puae.md`.
Base réutilisée : `docs/design/v2.0-atari-st.md` (infrastructure « ordinateur »). Ce document ne donne que le **delta**
par rapport à la 2.0. Les signatures ci-dessous seront **posées dans le code par l'`architecte` au lancement de la
3.0**, une fois la 2.0 intégrée (le code fera alors foi) ; aucune n'est posée aujourd'hui.

## 2. Fonctionnement

### 2.1 Lancement d'un jeu Amiga depuis la bibliothèque

```text
Game (amiga, media = [d1, d2]) ─ choose_core ─► puae
  modèle = options du jeu > [core_options.puae] > resolve_amiga_model(chemin, Disquette|DisqueDur, puae_model_fd/hd)
  kickstart_for_model(puae, modèle) = "kick34005.A500" ─ check_firmware ─┐
     Ok            ─► puae_kickstart = "auto"
     Missing       ─► puae_kickstart = "aros", FirmwareState::CoreFallback ; 1re fois pour ce jeu : dialogue
                      « Pas de Kickstart A500 : AROS intégré (compatibilité limitée) [Importer un Kickstart…] [Continuer] »
     WrongHash     ─► dialogue 1.0 : [Lancer quand même] [Utiliser AROS] [Importer…]
options : défauts core < cores.toml (puae_mapper_select = "---", puae_mapper_mouse_toggle = "---", …) < config < jeu
          + puae_kickstart calculé (non mémorisé, sauf si l'utilisateur l'a fixé pour ce jeu)
Emulator::load_content(core, ContentSpec::Media { set, rules: MediaRules { WorkingCopy, direct = [ipf, lha] } })
   ─► prepare_media : d1, d2 copiés dans saves/puae/<jeu>.disks/ ; zip de disquettes extrait ; <jeu>.m3u généré
   ─► puae MultiDrive : d1 → DF0, d2 → DF1 ; menu Disquettes / Hôte + D agissent sur DF0
mode d'entrée initial = Clavier (souris capturée au premier clic) ; OSD « Ctrl droit : menu · Ctrl droit + J : joystick »
```

Entrée « Workbench / AROS » de la bibliothèque (système `amiga`) : `ContentSpec::NoGame` (A500 + Kickstart si présent,
sinon écran AROS « Waiting for bootable media »), mode *Clavier*.

### 2.2 Import d'un BIOS

```text
[Importer un BIOS…] ─► pick_file (rfd natif | navigateur egui) ─► identify_firmware(src, &catalogue)
   Known { targets: [kick34005.A500] } ─► pour chaque cible : target_state
        Absent | FreeInstalled ─► import_firmware(…, Refuse) ; Same ─► « déjà installé »
        Other { md5 }          ─► « Remplacer ? l'ancien deviendra kick34005.A500.user-<unix> » ─► BackupAndReplace
   AmigaForeverEncrypted       ─► import non vérifié sous le nom Amiga Forever + « copiez aussi rom.key »
   Unknown { md5 }             ─► refus expliqué ; [Importer quand même…] ─► choix du nom parmi expected_names() ─► verified = false
```

### 2.3 Ouvrir le dossier des ROMs

```text
[Ouvrir le dossier des ROMs] ─► roots = [<data>/roms] + library.roots (créé s'il manque)
   1 dossier : open_folder(dossier) ; plusieurs : menu
   open_folder : conteneur (EMU_RUST_CONTAINER=1) ─► ShowPath { /data/roms, EMU_HOST_ROMS_DIR? }
                 sinon opener::open(dossier) ─► Ok : Opened ; Err : ShowPath (chemin + [Copier])
```

### 3.1 `emu-libretro`

Pas d'API nouvelle. Environnement : répondre explicitement `false` à 28 `GET_PERF_INTERFACE`, 45

### 3.2 `emu-runtime`

```rust
pub struct MediaRules {                       // remplace le paramètre `MediaPolicy` seul
    pub policy: MediaPolicy,                  // politique par défaut du core
    pub direct_extensions: Vec<String>,       // jamais copiées (puae : ipf, lha)
    pub max_copy_bytes: u64,                  // 2 Gio (HDF) ; au-delà : InvalidMediaSet
}
impl MediaRules { pub fn new(policy: MediaPolicy) -> Self }   // direct_extensions vide, MAX_COPY_BYTES
pub const MAX_COPY_BYTES: u64 = 2 << 30;
pub fn prepare_media(set: &MediaSet, rules: &MediaRules, accepted_extensions: &[String], saves_core_dir: &Path)
    -> Result<PreparedMedia, RuntimeError>;
pub fn reset_working_copies(saves_core_dir: &Path, game: &str) -> Result<bool, RuntimeError>;  // + <jeu>.save*.adf
ContentSpec::Media { set: MediaSet, rules: MediaRules }
RuntimeError += DiskFull { path: PathBuf }     // copie partielle supprimée
```

Règles : une image dont l'extension est dans `direct_extensions` est référencée à son emplacement d'origine dans le
`.m3u` généré (chemin absolu) ; un zip est inspecté sans extraction : s'il contient au moins une image acceptée (hors
`zip`/`7z`), il est extrait comme en 2.0, sinon il est transmis tel quel comme contenu unique (le core le traite comme
un dossier ; écritures perdues, documenté). `#SAVEDISK:` d'un `.m3u` utilisateur est recopié tel quel dans le `.m3u`
de travail. `reset_working_copies` supprime aussi `saves_core_dir/<jeu>.save*.adf` (disquettes de sauvegarde créées
par puae à partir du nom du `.m3u`).

### 3.3 `emu-assets`

```rust
// cores/firmware.rs
pub enum FirmwareState { …, CoreFallback { label: String } }   // AROS intégré : ni « manquant » ni bloquant
// cores/select.rs (CorePreferences)
pub fn media_direct_extensions(&self, core: &CoreId) -> Vec<String>;
pub fn builtin_fallback(&self, core: &CoreId) -> Option<BuiltinFallback>;
pub struct BuiltinFallback { pub label: String, pub option: String, pub value: String }  // ("AROS (intégré au core)", "puae_kickstart", "aros")
pub fn firmware_for_model(&self, core: &CoreId, model: &str) -> Option<String>;          // "A500" -> "kick34005.A500"
// bios/import.rs (nouveau sous-module de bios.rs)
pub struct FirmwareCatalogue;   // md5 -> noms attendus, depuis firmware.toml + .info installés + free_bios
impl FirmwareCatalogue {
    pub fn build(known: &KnownFirmware, infos: &[(CoreId, CoreInfo)], free: &[FreeBios]) -> Self;
    pub fn expected_names(&self) -> Vec<ExpectedFirmware>;           // pour l'import non vérifié
}
pub struct ExpectedFirmware { pub name: String, pub label: String, pub system: Option<String>, pub size: Option<u64> }
pub enum Identification {
    Known { md5: [u8; 16], sha1: [u8; 20], size: u64, targets: Vec<ExpectedFirmware> },
    AmigaForeverEncrypted { size: u64, suggested: Option<String> },  // en-tête "AMIROMTYPE1"
    Unknown { md5: [u8; 16], sha1: [u8; 20], size: u64 },
}
pub enum TargetState { Absent, Same, Other { md5: [u8; 16] }, FreeInstalled }
pub struct ImportOutcome { pub installed: PathBuf, pub backup: Option<PathBuf> }
pub const MAX_FIRMWARE_BYTES: u64 = 16 << 20;
pub fn identify_firmware(src: &Path, catalogue: &FirmwareCatalogue) -> Result<Identification, BiosError>;
pub fn target_state(system_dir: &Path, name: &str) -> Result<TargetState, BiosError>;
pub fn import_firmware(system_dir: &Path, src: &Path, name: &str, policy: ReplacePolicy, verified: bool)
    -> Result<ImportOutcome, BiosError>;
BiosError += TooLarge(u64), InvalidTargetName(String), TargetExists(String)
```

Règles d'import : `name` validé (non vide, pas de `..`, pas de chemin absolu, séparateur `/` seulement si le nom
vient d'un `.info` qui déclare un sous-dossier) ; source relue en flux (jamais chargée au-delà de 16 Mio) et **hash
recalculé sur la copie** avant renommage ; temporaire dans `system/`, `sync_all`, renommage ; `Refuse` sur un
fichier `Other` ⇒ `TargetExists` ; `BackupAndReplace` ⇒ `<nom>.user-<unix>` ; `FreeInstalled` (EmuTOS posé par nous
sous `tos.img`) remplacé sans sauvegarde et retiré du manifeste ; table `[imported."<nom>"]` (`source` = nom de
fichier seul, `md5`, `verified`) dans `system/.emu-rust-bios.toml`.

## 8. Risques

| Risque | Atténuation |
|---|---|
| Beaucoup de jeux ne marchent pas sous AROS | Dialogue explicite, import guidé du Kickstart, AROS seulement en repli |
| `rfd` échoue silencieusement sous Linux sans portail ni zenity (renvoie `None` comme une annulation) | Détection préalable (`picker_backend`) + lien « navigateur intégré » toujours présent dans le dialogue |
| `opener` sous Docker sur WSL2 détecte « WSL » (noyau Microsoft) et tenterait `explorer.exe` | Docker détecté par `EMU_RUST_CONTAINER` **avant** tout appel à `opener` |
| Touche Windows interceptée par le système (Démarrer, Win + E…) | Documenté ; Amiga gauche aussi au clavier virtuel ; question §9.2 |
| Géométrie variable (lores / hires / entrelacé) | Déjà géré (`av_info_changed`) ; vérifié par Q5 sur le bureau AROS 720×574 |
| Nightly puae change l'AROS intégré ou les options | Version précédente conservée (ADR 0013), empreintes ré-enregistrées, puae2021 en alternative |

## 9. Questions pour l'utilisateur (défaut appliqué sans attendre ; recommandation entre parenthèses)

1. **Core Amiga** : `puae` (WinUAE 5.3.1, plus précis, plus lourd) par défaut et `puae2021` (plus léger) en un clic,
   ou l'inverse pour le Mac Intel ? (*puae* ; on bascule le Mac sur puae2021 si l'essai montre des ralentissements.)
2. **[DÉCIDÉ : Alt gauche / Alt droit, hôte Ctrl droit partout]** **Touches Amiga sur le Razer 60 %** : Amiga gauche = touche Windows (limite : Windows peut ouvrir Démarrer ou réagir
   à Win + lettre), Amiga droite = touche **Menu** (Ctrl droit reste la touche hôte) ? Sur macOS : Amiga gauche = ⌘
   gauche, Amiga droite = **Option droite** (⌘ droit est la touche hôte) ? Autres choix possibles : touche hôte macOS
   = Option droite et Amiga droite = ⌘ droit ; ou Amiga gauche / droite = Hôte + `<` / Hôte + `W`. (*Windows / Menu ;
   ⌘ gauche / Option droite* ; modifiables dans `config.toml`.)
3. **Kickstart absent** : lancer automatiquement avec AROS après un avertissement unique par jeu, ou refuser et
   demander d'importer un Kickstart ? (*AROS avec avertissement unique*.)

5. **Modèle par défaut** : `auto` de puae (A500 Kickstart 1.3 pour les disquettes, A1200 pour WHDLoad) ? Tes jeux
   point-and-click (Monkey Island, Indiana Jones…) tournent en A500 ; les versions AGA demandent A1200. (*auto*.)
6. **Kickstarts que tu possèdes** : 1.3 (A500) et/ou 3.1 (A1200), sous quels noms (Amiga Forever chiffrés avec
   `rom.key`, ou ROM brutes) ? Utile pour l'essai, aucun besoin de les envoyer. (*question d'information*.)
7. **IPF** : faut-il prévoir l'import guidé de `capsimg` (bibliothèque SPS, non redistribuable) dès la 3.0, ou les

8. **Docker** : afficher le chemin `/data/roms` + l'aide `docker cp`, et proposer dans `compose.yaml` un montage d'un
   dossier Windows/WSL (variable `EMU_HOST_ROMS_DIR`) pour déposer les ROMs directement ? (*oui, montage commenté*.)
9. **Sélecteur de fichier** : dialogue natif du système (`rfd`) partout où il fonctionne, navigateur egui intégré sous
   Docker et en repli ? Faut-il aussi l'utiliser pour choisir les dossiers de la bibliothèque (aujourd'hui champ texte) ?
