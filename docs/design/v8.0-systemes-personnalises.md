# Conception 8.0 — systèmes personnalisés (cartouches et fichier unique, rendu logiciel)

Date : 2026-11-25 (architecte), amendée le même jour après la revue indépendante (`.claude/rv-8.0.md`), sa
relecture et les réponses de l'utilisateur aux 12 questions 8.0 (Q1, Q5 et Q12 autres que le défaut).
Décisions : **ADR 0025** (proposé), qui fait foi ; étude `docs/essais-systemes-personnalises.md` (§10 : réponses de
l'utilisateur) ; essais `docs/plan-essais-8x-9x.md`. Branche : `wip-8.0`, créée depuis la tête de la dernière
version livrée (`wip-7.2`, ou `wip-7.2.1` si le glisser-déposer est livré avant), fusions vers l'aval seulement
(`docs/design/integration-largeur.md` §1). Paliers suivants : 8.1 CD, 8.2 ordinateurs, 8.3 arcade, 9.0 rendu
matériel.

## 1. Fonctionnement (parcours de l'utilisateur)

1. Écran Cores → « Vérifier les mises à jour » (existant) → « Ajouter un système non testé… ».
2. Liste filtrée (émulateurs non expérimentaux ; « Tout afficher ») ; recherche par machine ; cores grisés avec
   leur palier (« prévu en 8.1 / 8.3 / 9.0 »).
3. Fiche : machine(s) à cocher (la première cochée ; machines CD grisées « 8.1 »), licence, BIOS annoncés,
   avertissements (expérimental, clavier en 8.2, pas d'états sauvegardés). « Ajouter ».
4. Core absent de `cores.toml` et pas encore accepté : avertissement « contenu non vérifié ».
5. Installation (gestionnaire existant) → sonde en processus enfant → définitions écrites → catalogue publié →
   `roms/<id>/` créé → scan incrémental → « Déposez vos jeux dans `roms/<id>/` » + « Ouvrir le dossier ».
6. Premier lancement de chaque jeu : avertissement « non testé » (sauf « Ça marche chez moi »), essai à blanc
   (quelques secondes, attente annulable), puis la partie. Témoin de lancement, SRAM comparée toutes les 60 s.
7. Réglages → Systèmes personnalisés : nom, extensions, cores, « Chercher la base d'identification », numéros
   ScreenScraper / IGDB, BIOS ignorés, « Recalculer depuis le core », « Supprimer » (jeux gardés, masqués) ;
   « Systèmes retirés » (« Restaurer », « Oublier ses jeux ») ; systèmes en erreur ; bascule vers un système
   officiel (bandeau ; par le rangement quand un dossier doit être déplacé).

## 3. Données de test (aucune donnée commerciale)

- `.info` synthétiques (`emu-assets`) : cartouche ; multi-machines mixte (cartouche + CD) ; rendu matériel avec trois
  API ; `hw_render = true` sans API ; CD seul (`cue|ccd|chd|toc|m3u`) ; arcade (`zip` seul) ; sans `database` ;
  valeurs parasites (`/`, `.`, `V32`) ; textes trop longs et caractères de contrôle ; extraits réels de l'étude §2.3.
- Définitions : valides ; une invalide par variante de `DefinitionError` ; `format = 2` ; `render = "hardware"` ;
  lien symbolique et FIFO ; 300 fichiers ; conflits avec un officiel (même id seul, même `database` seule, les deux) ;
  système sans `database` qui demande un id de la table (refusé) ; noms à `/` (`systemname` réels, normalisation) ;
  catalogue officiel et `cores.toml` synthétiques pour la bascule ; profil de touches officiel déjà présent et
  différent ; arborescence `roms/<id perso>/` avec un conflit à la destination (bascule non proposée).
- Core factice (`tests/mock-core/mock_core.c`, `qa-systems`), chaque comportement derrière sa variable,
  défaut inchangé : `MOCK_HW_RENDER=<ctx>,<maj>,<min>`, `MOCK_HW_FRAME=1`, `MOCK_NO_FRAME=1`,
  `MOCK_CRASH_AT_FRAME=<n>`, `MOCK_HANG_AT_FRAME=<n>`, `MOCK_LOG_FLOOD=1`, `MOCK_DESCRIPTORS=1` (texte de 300
  caractères, caractères de contrôle), `MOCK_EXTENSIONS=<liste>`, `MOCK_WRITE_CONTENT=1` (écrit dans le jeu).
- Réel (`#[ignore]`, SHA-256 épinglés par `platform-build`) : `stella` et `mednafen_pce_fast` (rendu logiciel) avec
  un homebrew de licence libre explicite chacun (choisi et cité par `platform-build`) ; `flycast` sans contenu.

## 5. Découpage

deux crates différents. Un seul worktree (`wip-8.0`) : `cargo` se sérialise sur `target/` ; disque serré ⇒ tests

entre les vagues.

comprises : PB1 réécrit `scan.rs` et `tidy/`, qui doivent être gelés en amont (sinon fusions conflictuelles).

## 7. Risques

| Risque | Effet | Parade |
|---|---|---|
| Catalogue changé pendant un scan ou un rangement | jeux classés sous deux catalogues | instantané capturé ; publication différée (PB1, PU2) |
| Régression des 17 systèmes officiels | jeux mal classés | PB1 seul, sans changement de comportement ; non-régression de l'attribution et du rapport (PB2) |
| Lecture oubliée de `.database` | requête ou fichier parasite | champ privé : la compilation force `libretro_name()` / `core_key()` ; test « zéro requête » |
| Bascule mal faite (Q16) | core changé en silence, sauvegardes invisibles | définition active prioritaire, bascule proposée seulement, cas « déplacement » reporté, instantané des clés de sauvegarde |
| Fusions amont sur `scan.rs` / `tidy/` | conflits lourds | préalable : 7.2 (et 7.2.1) fusionnées avant PB1 |
| Core qui plante en partie | application fermée | témoin, SRAM, message au redémarrage |
| Enfant d'essai bloqué (boîte, journal, parent mort) | attente, disque | aiguillage en tête, sorties nulles, chien de garde, revue PV2 |
| Dialogue de plantage macOS | gêne | limite notée ; essai n° 7 |
| `.info` faux | jeux non vus, avertissements inutiles | sonde, « Recalculer », « Ne plus avertir » |
| Rotation non gérée | jeux Lynx verticaux mal orientés | California Games horizontal (**non vérifié**) ; essai n° 4 |
| BIOS en arborescence (bluemsx) | MSX non démarrable | guide ; repli `fmsx` ; réponse Q10 |
| Bascule avec déplacement interrompue ou partielle | jeux sur un système disparu | jamais proposée avec une unité bloquée ; journal version 2, reprise idempotente, annulation qui restaure la définition (PB3, PU4) |
| Disque (~24 Go libres) | builds en échec | un worktree, tests ciblés, `incremental` purgé |

## 8. Points à re-valider contre le code de `wip-8.0`

- Signatures remplies par chaque agent (`plan_launch`, `LaunchArgs`, `save_config` après 7.1 / 7.2).
- Littéraux complets de `ScanOptions`, `DataDirs`, `CoreInfo` (PX0 : compléter par `..Default::default()`).
- `Emulator` utilisable sans sortie audio et sans rythme pour `dry_run` (PR1).
- 7.2.1 livrée avant la 8.0 ou non : ADR 0025 §12 s'impose à sa conception.
