# 7.5 — Finition PC : contrat de fusion et découpage (L1-L6)

Statut : **contrat** (2026-11-25, architecte, lot L0 de `.claude/fusion-plan.md`). Branche `wip-7.5`, partie de
`main` 7.4.0. Les décisions D1 à D15 de l'utilisateur (plan de fusion) font autorité ; ce document fixe les
signatures et types partagés que les lots L1 à L6 réalisent, sans logique. Sources : ADR 0023 (amendée), 0024
(amendée), 0021 (amendement alias PS1), 0020 (réécrite, GV1), 0005 ; code PC des refs `wip-7.1` / `wip-7.2`
(réappliqué en lisant les diffs, jamais par fusion ni cherry-pick global).

**Graphe des crates inchangé. Schéma de `library.sqlite` inchangé (v7, 7.4). Aucun code réseau nouveau** hors la
lecture de l'en-tête `Last-Modified` d'une réponse du buildbot déjà demandée (message « buildbot en cours de mise à
jour »). **Un seul `unsafe` nouveau** : `MessageBoxW` (`emu-runtime::dialog`), revue `reviewer`.

## 3. CD 32X : reconnaissance (D4, D8, D9)

```rust
// crates/emu-library/src/disc.rs (L3) — nom et rôle Mac gardés, règle PC normalisée
/// Parenthesised Sega CD 32X tag: `Sega CD 32X`, `Mega-CD 32X`, `Mega CD 32X`, `32X CD`, `CD 32X`
/// (ASCII case ignored, `-` read as a space, inner spaces collapsed). A bare `(32X)` is refused (D9).
pub fn name_needs_32x(name: &str) -> bool;
pub fn disc_needs_32x(path: &Path) -> Result<bool, LibraryError>; // inchangé (sonde 7.4)
```

- Le scan pose `game.needs_32x` = sonde **ou** `name_needs_32x` sur le titre DAT, le nom du fichier **ou** le nom
  d'un des disques (`game.media`) : un disque suffit (`.m3u`, groupes `(Disc N)`).
- Ligne déjà scannée avec `needs_32x = false` : la règle du nom (sans lecture de fichier) est réévaluée à chaque
  scan, pour que les formes nouvelles de la 7.5 marquent les jeux d'une base 7.4 sans rescan complet. La sonde ne
  l'est pas (rescan complet).
- `cd32x_tag` (PC) n'est pas porté : ses formes passent dans `name_needs_32x`. Le test PC `cd32x_tag_forms`
  devient un test de `name_needs_32x`, avec `(32X)` nu **refusé**.
- Borne de CRC de la piste 01 Mega CD : **512 Mio** (D8 ; la borne PC de 800 Mio n'est pas portée).
- Marque manuelle : `[library] cd32x` (§4). Pastille « 32X » (`theme::badge`) et invitation dans la ligne d'aide
  (« Jeu Sega CD 32X ? Clic droit ou X → Ce jeu est un CD 32X ») pour un `megacd` non marqué identifié `Unknown` /
  `Name`.
- **Clic droit sur une vignette : un seul menu** (conflit 9) : « Réinitialiser la jaquette » (7.3, touche **R**) et
  « Ce jeu est un CD 32X » / « Ce n'est pas un CD 32X » (jeux `megacd` que leur nom ou la sonde ne marque pas,
  touche **X**). Un jeu marqué par la sonde ou le nom n'a pas l'entrée 32X.
- Écriture de `config.toml` impossible ⇒ marque annulée en mémoire, échec affiché (ADR 0024 §2).
