# Table des ids 8.0 (`libretro_ids.toml`) — contenu cible relu par l'architecte (lot PC1)

Relue le 2026-11-27 par l'architecte seul (ADR 0025 §3, réponse Q12 : l'utilisateur ne veut pas voir la liste).
À reporter par `library-assets` dans `crates/emu-library/data/libretro_ids.toml` (corrections PC1, avant PU2) ;
ce fichier fait foi jusqu'au tag de la 8.0, puis la table embarquée fait foi (ajouts seulement).

## Source

- **Noms `database` cités par les `.info`** : dépôt `libretro/libretro-core-info`, branche `master`, commit
  `eac3a2784d42` (2026-11-02), 351 fichiers `.info` : champ `database`, coupé sur `|`, espaces retirés.
  174 valeurs distinctes, dont deux écartées : `""` (deux `.info` sans nom) et `null` (`3dengine`, pas une
  machine). Restent **172 noms**, tous dans la table (l'étude du 2026-11-21 en comptait 165 ; le dépôt a grandi).
- **Noms de `libretro/libretro-database`** (commit `f89f09cbe13f`, 2026-11-23 : `rdb/*.rdb`, `metadat/**.dat`,
  `dat/*.dat`) : servent à garder **12 entrées** de la table provisoire qu'aucun `.info` ne cite aujourd'hui mais
  qui sont de vrais noms libretro (un core futur les citera ; leur id, choisi maintenant, ne sera pas une
  réduction suffixée).
- **Retirées** : 41 entrées de la table provisoire. 40 n'existent sous ce nom ni dans les `.info` ni dans
  libretro-database (noms écrits de mémoire : `Mattel - HyperScan` au lieu de `HyperScan`, `Sammy - Atomiswave` au
  lieu de `Atomiswave`, `Philips - P2000` au lieu de `Philips - P2000T`…) ; une (`NEC - PC-8001 - PC-8801`) doublerait
  la machine que le core `quasi88` cite sous `NEC - PC-88`. Aucune n'a été publiée : les retirer n'est pas un
  renommage au sens de l'ADR 0025 §3.

Total : **184 entrées** (172 + 12) ; paliers : 107 `cartridge`, 35 `computer`, 24 `disc`, 18 `arcade`.

## Règles de choix

- Id = réduction du nom (ADR 0025 §3) quand elle est lisible ; sinon un id court choisi ici, une fois pour toutes :
  `atari8bit`, `enterprise128` (la réduction serait `128`), `handheld` (`gw`, « Handheld Electronic Game »),
  `svi318`, `pc88`, `j2me` / `javame` (deux noms pour la même plate-forme : `Mobile - J2ME`, cité par deux cores,
  prend `j2me`). Ids repris d'entrées retirées : `atomiswave`, `hyperscan`, `playdia`.
- Palier : `disc` pour une machine à CD ou DVD (grisée « prévu en 8.4 ») ; `arcade` pour les jeux d'arcade et les
  versions de MAME (« prévu en 8.6 ») ; `computer` quand le clavier est nécessaire (ordinateurs, Z-Machine,
  machines d'apprentissage) ; `cartridge` pour le reste, moteurs de jeux et consoles imaginaires compris (fichier
  unique). Les versions numériques (`Nintendo - Wii (Digital)`, DSi) sont `cartridge` : fichiers uniques, pas des
  disques ; le rendu matériel les grise de toute façon (« prévu en 9.0 »).
- Noms hors liste blanche : seul `BK-0010/BK-0011` (`/`) ; exception au fichier DAT local `BK-0010_BK-0011`.
- Les 17 systèmes officiels gardent leur id.
