Third-party data embedded in emu-rust
=====================================

Firmware reference hashes (crates/emu-assets/data/firmware.toml, embedded in the binary)

  Title:    libretro-database, dat/System.dat (v1.19.0)
  Author:   libretro-database contributors
  Source:   https://github.com/libretro/libretro-database
            commit 2a8de0276fd7d3095f2501c3de3799a14c37e910
  License:  Creative Commons Attribution-ShareAlike 4.0 International (CC-BY-SA-4.0)
            https://creativecommons.org/licenses/by-sa/4.0/

  Sections of System.dat used: Atari - ST; Commodore - Amiga; Commodore - C128 (JiffyDOS files only); DOS
  (MT-32 / CM-32L ROMs only); Nintendo - Famicom Disk System, Game Boy, Game Boy Advance, Game Boy Color,
  Satellaview, SuFami Turbo, Super Game Boy; Sega - Game Gear, Master System - Mark III, Mega CD - Sega CD,
  Mega Drive - Genesis.

  Changes: only the md5 checksums (and, for some entries, the file size in bytes) of firmware (BIOS) files were
  extracted and reorganised into a TOML table keyed by file name. No firmware file is included.

  The embedded data file is a derivative work and is distributed under the same
  license, CC-BY-SA-4.0. It is data only: it does not change the license of the
  emu-rust program (MIT OR Apache-2.0).
